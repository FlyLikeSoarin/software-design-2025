# Участие в проекте (Contributing)

При внесении изменений в этот репозиторий, пожалуйста, создайте Pull Request и укажите одного из мейнтейнеров в качестве рецензента. Это:
- alexandra-tsepkova
- FlyLikeSoarin
- SheLesTT
- mixassio

## Требования

- Убедитесь, что любые зависимости для установки или сборки удалены до завершения слоя при выполнении сборки.
- Обновите файл `README.md`, добавив сведения об изменениях интерфейса, включая новые переменные окружения, открытые порты, полезные пути к файлам и параметры контейнера.
- Вы можете объединить Pull Request после получения одобрения от двух других разработчиков. Если у вас нет прав на это, вы можете попросить второго рецензента выполнить слияние за вас.
